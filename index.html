D141 Site Setup

Prototype hub

Mockup only - fake data - Proposal unless owner-stated

Capturing D141 camera site data directly in Salesforce (CMCS) with validation at the point of entry, instead of an Excel form that is re-keyed. The spreadsheet layout does not have to be copied: the outcome is validated, complete site details feeding CMCS. Each variation below is a separate, Lightning-styled prototype of the same data model (five record types: FDSC, RLSC, BPES, ASC, ODES).

Capture variations

1. Guided single-site record page Skeleton - in progress

Site list, New Site with record type picker, then a Lightning record page with a Path across the lifecycle, stage-gated sections, inline edit and attachments.

Use it for
Entering or maintaining one site, following it through each lifecycle stage.
Prefer when
A TPM is working a single site over weeks and needs the stage gates and attachments in one place.

2. Bulk grid entry Skeleton - in progress

Editable grid of several sites with per-row validation, a bulk action bar (Commission, Decommission, Refurbish, mark stage complete, set value).

Use it for
Entering or changing many sites at once (a batch of installs, a decommission run, a refurbishment programme).
Prefer when
The same few fields change across many sites and speed matters more than per-site guidance.

3. Guided screen flow Skeleton - in progress

Step-by-step wizard (Screen Flow style): program, activity, location, equipment, network, school zone, review. One concern per screen with validation before Next.

Use it for
First-time creation of a site by someone who does not know the data model.
Prefer when
Fewer mistakes matter more than speed; new or occasional users.
